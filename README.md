# Agustinus Yogi

Sarjana Komputer dari Aradide, Paniai — Papua Tengah. Di sini saya bekerja di
bidang teknologi sekolah: membangun sistem yang dipakai sekolah, menjaga
server tetap hidup, dan berbagai hal-hal lain yang harus tetap jalan.

## Tentang saya

- 🔧 **Pengembang aplikasi sekolah** — sistem manajemen sekolah terpadu: website
  publik, PPDB, LMS, penilaian, absensi, hingga administrasi.
- 🛡️ **Sibuk dengan keamanan** — prepared statement, token CSRF, bcrypt, upload
  yang divalidasi berlapis, dan pesan error yang tidak bocor ke pengunjung saat
  produksi.
- ☁️ **Bisa jalan sendiri** — Apache, PHP, MySQL/MariaDB, sampai deploy ke
  Google Cloud beserta SSL. Tidak perlu Docker, tidak perlu framework.
- 📝 **Mau berbagi** — menulis di [bukabagusy.net](https://bukabagusy.net).

## Yang saya kerjakan

**Aradide Smart School** — sistem manajemen sekolah untuk SMP Negeri 1 Aradide,
Papua Tengah. Ditulis dari nol memakai PHP murni tanpa framework dan tanpa
Composer, supaya bisa jalan di shared hosting yang murah maupun di server
sendiri.

Yang membuatnya tidak sekadar CRUD biasa:

- **LMS** lengkap dengan kelas, rombel, jurnal, absensi, nilai, tugas, kuis, dan
  forum
- **Portal PPDB** dengan pendaftaran online dan pengecekan status
- **Keanggotaan kelas** yang selalu sinkron dengan rombel, bukan input manual
- **Video conference** memakai Jitsi Meet
- **Portal alumni** dan direktori yang bisa dikelola sendiri
- **AI chatbot** untuk menjawab pertanyaan pengunjung di website sekolah

## Tech yang dikuasai

**Backend** — PHP 8, MySQL & MariaDB, PDO, Apache

**Frontend** — Bootstrap 5, Chart.js, JavaScript, CSS (termasuk glassmorphism)

**Operasional** — konfigurasi server, SSL, backup otomatis, Google Cloud
Compute Engine

## Prinsip kerja

> Kalau butuh framework untuk menjalankan satu form, berarti framework-nya
> yang berlebihan.

Saya lebih suka hal yang bisa di-debug tanpa tools tambahan. Kode yang masih
terbaca enam bulan kemudian lebih berharga daripada kode yang jalan sekarang
tapi tidak ada orang yang paham.
